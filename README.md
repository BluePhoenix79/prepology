# Preplogy - SAT Prep Platform

Preplogy is a comprehensive SAT prep platform with real question bank integration, adaptive practice, and detailed rationale feedback.

## Features
- **Adaptive Practice**: Personalized question sets.
- **Detailed Rationale Feedback**: Learn from your mistakes with in-depth explanations.
- **MathJax Integration**: High-quality rendering for mathematical equations and formulas in the browser.

## Tech Stack
- **Framework**: [Vite](https://vitejs.dev/) (Vanilla TypeScript)
- **Language**: TypeScript
- **Styling**: Vanilla CSS
- **Math Rendering**: MathJax

## Getting Started

Follow these steps to get the project up and running locally:

### 1. Install dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

The development server will start. Check your terminal output for the local URL (usually `http://localhost:5173/`).

### 3. Build for Production
```bash
npm run build
```

This will compile the TypeScript code and output the production-ready static files into the `dist` folder.
